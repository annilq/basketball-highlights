# 国际化方案实施计划

## 1. 配置 Astro i18n

- 修改 `astro.config.mjs`，添加 i18n 配置
- 设置 `locales: ["en", "zh"]` 和 `defaultLocale: "en"`
- 配置 `routing: { prefixDefaultLocale: false }`，使英文页面无需前缀

## 2. 创建语言切换组件

- 在 `layouts/BaseLayout.astro` 中添加语言切换 UI
- 位于导航栏右侧，与现有按钮风格保持一致
- 使用 `getRelativeLocaleUrl` 生成正确的语言切换链接

## 3. 确保页面正确响应语言切换

- 修改 `BaseLayout.astro` 中的 `<html lang="en">` 为动态语言
- 确保所有页面链接使用相对路径，支持语言切换

## 4. 测试与验证

- 启动开发服务器，测试语言切换功能
- 确保所有页面在中英文切换时正常显示
- 检查无运行时错误

## 预期效果

- 英文默认 URL：`/about`
- 中文 URL：`/zh/about`
- 导航栏右侧添加语言切换按钮（EN/中文）
- 点击切换按钮后，页面平滑切换到对应语言版本

## 技术要点

- 使用 Astro 内置的 i18n 功能，无需额外依赖
- 遵循 Astro 最佳实践，确保路由正确
- 保持现有 UI 风格统一
- 确保 SEO 友好，正确设置 lang 属性
