## 实现计划

### 1. 后端API扩展 (api/routers/shotDetection.ts)

- **添加generateShotClip端点**
  - 输入：videoUrl或video文件，shot_frame，duration

  - 调用Python服务的/generate-shot-clip端点

  - 处理不同输入类型（URL或文件上传）

  - 返回生成的片段路径

- **添加generateHighlights端点**
  - 输入：videoUrl或video文件，可选output_path

  - 调用Python服务的/generate-highlights端点

  - 处理不同输入类型（URL或文件上传）

  - 返回生成的集锦路径

### 2. 前端查询扩展 (app/lib/queries/shot-detection.ts)

- **添加useGenerateShotClipMutation钩子**
  - 处理片段生成API调用

  - 管理加载和错误状态

- **添加useGenerateHighlightsMutation钩子**
  - 处理集锦生成API调用

  - 管理加载和错误状态

### 3. 前端UI修改 (app/routes/(app)/shot-detection.tsx)

- **添加生成集锦按钮**
  - 在现有提交按钮旁边添加新按钮

  - 点击时调用generateHighlights API

  - 显示加载状态和结果

- **修改ShotEvent组件**
  - 添加生成片段按钮

  - 点击时调用generateShotClip API，传递当前事件的frame

  - 显示加载状态和结果

### 4. 数据库扩展（如果需要）

- 考虑是否需要将生成的片段和集锦信息保存到数据库
